## 🎮 How to Use tomodachi-pc

When you first open the program, you see a simple window with a few buttons.

### Step 1 – Choose Your Game Files
You need a copy of *Tomodachi Life: Living the Dream* (the Nintendo Switch version).  
Click the **Select Game** button and browse to the folder or file of your game (usually a `.nsp` or `.xci` file).

- **QR Code Sharing** – Scan QR codes to import or export Mii characters.

### Step 3 – Start the Game
Press the **Play** button. The Ryujinx emulator launches and loads the game.  
You can now play *Tomodachi Life* on your PC with better graphics and performance.

### Step 4 – Manage Your Island
From the tomodachi-pc main menu you can also:

- Open the **Save Editor** – Change your island name, unlock all items, or edit Mii personalities.  
- Share Miis – Click **QR Code** to show a code that other players can scan.  
- Tweak settings – Adjust volume, controller mapping, or resolution.

## ❓ Frequently Asked Questions

**Q: Do I need the Ryujinx emulator separately?**  
No. tomodachi-pc includes its own tuned version of Ryujinx. You only need the installer.

**Q: Where do I get the game files?**  
You must own a copy of *Tomodachi Life: Living the Dream* from the Nintendo Switch eShop or a game cartridge. Dump the files legally using your Switch. We cannot provide game files.

**Q: Will this work on Windows 7 or 8?**  
No. tomodachi-pc requires Windows 10 or 11 (64-bit). Older Windows versions lack needed drivers.

**Q: The game lags or stutters. What can I do?**  
Try lowering the resolution to 720p in the settings. Also close other programs to free up RAM. If you have an NVIDIA graphics card, make sure you run the game on the dedicated GPU (not the integrated one).

**Q: How do I use QR codes?**  
Open the QR Code tool inside tomodachi-pc. A code appears on your screen. Use your phone’s camera or a QR code scanner app to read it. The Mii data will be saved on your device or shared online.

**Q: Can I use my existing Ryujinx saves?**  
Yes. Place your save files in the folder that tomodachi-pc shows in the Save Editor section. The program reads them automatically.

## 🛠️ Troubleshooting

**The installer says “Windows protected your PC.”**  
This happens because the program is unsigned (a common situation for open-source tools). Click **More info** then **Run anyway**. It is safe.

**The game opens but shows a black screen.**  
Wait a few seconds. If it persists, check that your graphics drivers are up to date. Also try turning off the HD texture pack from the main menu.

**QR code scanning does not work.**  
Make sure your camera is clean and the code is fully visible. If using a phone, try a different QR code app. The code updates every few seconds.

**The program crashes on launch.**  
Reinstall the latest version. If the problem continues, delete the folder `%appdata%\tomodachi-pc` and try again. This resets your settings.
